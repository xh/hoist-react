<objective>
Build the interactive harness UI as a Toolbox example app: a scenario picker (configs persisted via
Hoist ViewManager), run controls that drive the framework's `MeasurementHarness` over the chosen
transport, an on-screen scorecard, and a side-by-side comparison of saved runs. Wire the client ingest
adapters that pull the out-of-process Grails data (02-02) into the harness over both HTTP and WebSocket.
Finally, document the harness in a framework README.

Purpose: Locked decisions - the interactive UI lives in Toolbox (public, demonstrable), configs are
named ViewManager JsonBlobs ("profiles and update patterns are data, not code"), comparison is a
first-class feature driven from saved runs, and each run is persisted + stamped with env metadata. This
is the last assembly step that makes the harness usable and demonstrably reusable (HARN-06). It carries a
human-verify checkpoint because the interactive run experience and the on-screen scorecard need a human
to confirm in a real browser with the GC/precise-memory flags.
Output: A `datalab` example app in Toolbox + a `data/measure/README.md`.
</objective>

`HttpIngestAdapter.ts`:
- `loadSnapshotAsync(shapeParams)`: `XH.fetchJson({url: 'datalab/snapshot', params})` (confirm fetch API
  via hoist tools) -> returns rows -> caller passes to `adapter.loadSnapshotAsync(rows)`.
- `nextDiffAsync(updateParams, cursor)`: fetch `datalab/diff` -> returns one batch -> caller applies via
  `adapter.applyDiffAsync(batch)`. Successive cursors return successive deterministic batches (HTTP poll).

`WebSocketIngestAdapter.ts`:
- Subscribe to the datalab WS channel via `XH.webSocketService` (the first-class WS-push transport).
- On each pushed batch, forward it to a supplied callback so the harness applies it via
  `adapter.applyDiffAsync(batch)`. Provide start/stop matching the server start/stop (02-02 Task 3).

Both adapters carry the SAME batch shape to the same two-op contract - only the delivery differs (the
clean `transport` knob from Pattern 1). Keep them small; they translate transport into ingest calls, they
do not measure. Element-factory/Hoist conventions; `null` over `undefined`; Async suffix.
