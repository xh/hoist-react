<objective>
Build the heap-attribution layer: a no-cross-origin-isolation default that reads whole-heap via
`performance.memory.usedJSHeapSize` (the existing Hoist precedent), calibrates per-record byte cost
per layer, and attributes resident heap to the four layers - cube store records, grid store records,
intermediate view-result rows - with AG Grid internals computed as the opaque remainder.

Purpose: HARN-04 requires heap attribution by layer with a fallback that does NOT require cross-origin
isolation. CONTEXT is explicit: the no-COI path (owned-object accounting + performance.memory) is the
PRIMARY path by intent; the precise COI API (`measureUserAgentSpecificMemory`) is a nice-to-have to be
SKIPPED if it threatens complexity, and it does not even produce a Hoist-layer breakdown (Pitfall 2).
This plan therefore implements only the no-COI accounting path. It depends on 02-01 types but is
independent of the boundary-timing plan (02-04 and 02-03 touch different files), so they run in parallel.
Output: `data/measure/HeapAttribution.ts`, exported from the measure barrel.
</objective>

  <name>Task 2: Per-record calibration + layered attribution with AG Grid remainder (HARN-04)</name>
  <files>data/measure/HeapAttribution.ts, data/measure/index.ts</files>
  <action>
In the same file, implement the accounting that turns whole-heap deltas into a per-layer attribution.

`calibratePerRecordBytesAsync(args: {loadNRowsAsync: (n: number) => Promise<void>; clearAsync: () => Promise<void>; n: number; settleMs: number}): Promise<number>`:
- forceGcAndSettle, read baseline heap, `loadNRowsAsync(n)`, forceGcAndSettle, read heap, return
  `(after - before) / n` as the per-record byte cost. Comment: object-valued-field shapes get their own
  calibration run, and shared object fields can make naive count x bytes double-count (RESEARCH Open
  Question 1) - so calibration is per field-shape and reported in the scorecard.

`attributeHeap(ctx: {baselineHeap: number; cubeRecordCount: number; gridRecordCount: number; viewRowCount: number; calibration: {cubeRecordBytes: number; gridRecordBytes: number; viewRowBytes: number}; method: HeapMethod}): HeapAttribution`:
- `totalDelta = heapNow() - ctx.baselineHeap`.
- owned layers = each count x its calibrated per-record bytes.
- `agGridInternals = Math.max(0, totalDelta - sumOfOwned)` - the OPAQUE REMAINDER (comment: AG Grid
  internal sizes are library-owned/opaque per Phase-1, measured as remainder, NEVER read from AG Grid
  source - cite the anti-pattern).
- return a `HeapAttribution` (the 02-01 type) populated with all four layers, totalHeapDelta, unit
  'bytes', and method.

Caller is responsible for calling forceGcAndSettleAsync before attributeHeap (document this); attributeHeap
itself just reads + computes so it stays pure/testable.

Add `export * from './HeapAttribution';` to `data/measure/index.ts`.
