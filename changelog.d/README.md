# Changelog fragments

Do not edit `CHANGELOG.md` directly. Each pull request adds its entries in a new markdown file in
this folder, and a release assembles them into `CHANGELOG.md`.

Add a one-line entry with `pnpm changelog add <section> "<text>"`.

Entry conventions are in [`docs/changelog-format.md`](../docs/changelog-format.md). The fragment
format and the commands are in the
[hoist-dev-utils README](https://github.com/xh/hoist-dev-utils/blob/master/README.md#changelog-fragments).
